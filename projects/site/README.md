# Utkal Project · site workspace

Start small and add implementation as the work requires it.

- `src/`: application source.
- `public/`: assets intended to be served by the application.
- `tests/`: tests added alongside meaningful behaviour.

This is an empty skeleton. It has no installed framework, dependencies, build command or deployment workflow yet. The `.gitkeep` files retain empty directories in Git; remove them when real files occupy those folders.

Repository settings live in root `utkal.config.json`. Plans, specifications and decisions live in [the project KB](../../kb/index.md). Public assets require the appropriate review before publication.

Astro is the agreed site direction. The existing local Astro preview remains unchanged. When site development starts, review and bring its source, approved assets and package/build files into this directory; preserve useful prior work. This skeleton does not replace that preview.
