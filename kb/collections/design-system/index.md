# Utkal Design System package

The current local source candidate is **0.1.0-rc.5**; see the [system guide](../../design-system/index.md). The downloadable **0.1.0-rc.2** archive is preserved as historical evidence, not the current source version. [Download the archived package](utkal-design-system-0.1.0-rc.2.tgz). It contains tokens, scoped CSS, original utility icons, fonts and their licences, and usage instructions. Review tools and website content are excluded.

[Original 0.1.0-rc.1 package](utkal-design-system-0.1.0-rc.1.tgz) is retained unchanged for history.
