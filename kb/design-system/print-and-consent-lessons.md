# Portable stories and optional measurement

The [visitor-readiness review](../research/product/visitor-readiness-2026-10-01.md) provides real evidence for two reusable patterns.

A printed story should keep its headings with the next paragraph, while allowing long notes to continue across pages. Do not force every long section into an unbreakable box. Check the final page and the source appendix on both A4 and Letter: a trailing margin can create a blank page. Preserve reader-selected notes, Odia glyphs and credits; screen success alone cannot establish print success.

Optional measurement should use a plain choice, a real decline action and a persistent route back to preferences. Keep the choice keyboard-accessible and explain its effect beside it. A disabled feature should make no provider request. Test both the consent state and the public-route boundary. No consent controls should appear in a downloaded book.

These lessons are applied in UTP's site components and print styles. They do not change the shared design-system package version or automatically alter other projects. Broader adoption should use evidence from those projects' own contexts.
